File Carving

Recover deleted files

Scan disk images to find files that no longer appear in the filesystem.

Source artifact: raw disk or partition image (dd, E01).

Start with what you're looking for:

  • Deleted documents, images, or executables — Foremost
  • Email addresses, URLs, credit card numbers, or other text patterns — Bulk Extractor
  • Specific file types with custom recovery rules — Scalpel

Foremost

Recover common file types from disk images.

Ready

Scans raw disk data for file headers and footers to reconstruct deleted files. Handles images, documents, archives, and executables out of the box. A good starting point when you don't know exactly what you're looking for.

Ready

Searches disk images for recognizable data patterns—email addresses, phone numbers, credit card numbers, URLs, and more. Useful when you need to answer "who was this machine communicating with?" or "what accounts were accessed?"
