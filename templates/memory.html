Memory Analysis

See what was running

Extract processes, network connections, and loaded code from RAM captures.

Source artifact: memory image (raw, crash dump, or LiME).

Use memory observations to guide and corroborate the investigation:

  • Which processes need closer examination? Compare parents, timestamps, command lines and loaded objects.
  • What network state was captured? Review endpoints and ownership, including possible stale records.
  • Do memory regions and kernel structures agree? Investigate differences with process and acquisition context.
  • What can be recovered for examination? Capture selected objects and corroborate them with disk artifacts and logs.
